# Product Overview

This is a **Form Builder** application that allows users to create, manage, and share custom forms with drag-and-drop functionality.

## Core Features

- **Form Creation**: Visual drag-and-drop form builder with various field types
- **Form Management**: Dashboard to view, edit, and manage created forms
- **Form Sharing**: Public URLs for form submission by end users
- **Analytics**: Track form visits and submissions
- **User Authentication**: Email/password authentication with session management
- **Responsive Design**: Works across desktop and mobile devices

## User Flow

1. Users sign up/sign in to access the dashboard
2. Create forms using the visual form builder
3. Publish forms and share via unique URLs
4. Monitor form performance through analytics
5. View and manage form submissions

## Target Users

- Content creators needing custom forms
- Small businesses collecting customer data
- Researchers conducting surveys
- Event organizers managing registrations
